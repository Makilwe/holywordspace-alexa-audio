# HolyWordSpace Alexa Audio

Public audio feed for the HolyWordSpace Alexa skill (Skill Blueprints, Spiritual Talks).

- `feed.xml` — the RSS 2.0 feed to paste into Blueprints as the audio link.
  `https://makilwe.github.io/holywordspace-alexa-audio/feed.xml`
- `be-still-know-that-i-am-god-song.mp3` — "Be Still, and Know That I Am God" (Psalm 46:10)
- `holy-spirit-come-song-fixed.mp3` — "Holy Spirit, Come — Lord, I Need You Every Day"
